# Madedown 1.3.2：软件内更新安装热修复

[English](https://github.com/zhxnix/Madedown/blob/v1.3.2/Docs/UPDATE_ANNOUNCEMENT_1.3.2.md) | **简体中文**

Madedown 1.3.2 修复点击软件内更新的“安装并重新启动”后一直转圈的问题。

## 重要：本次请手动安装

缺陷存在于当前正在运行的 1.3.0 和 1.3.1 中，因此这两个版本无法可靠地通过软件内更新安装本次修复。**本次更新请不要点击“安装并重新启动”。** 请从 GitHub Releases 下载 `Madedown-1.3.2.dmg`，手动替换一次 `Madedown.app`。从 1.3.2 开始，后续版本即可通过 **帮助 → 检查更新…** 完成校验后的原位更新。

## 修复内容

- 请求 AppKit 退出应用前，先关闭更新窗口。
- 等待模态 Sheet 完全脱离后，才启动更新助手并退出。
- 应用会持续持有并监控更新助手进程。
- 如果助手未完成安装便退出，更新界面会显示错误并清理准备目录，不再无限转圈。
- DMG 准备流程会释放目录枚举资源并重试卸载，避免已挂载镜像阻止工作目录清理。

## 原因与验证

旧版更新器在模态更新 Sheet 仍挂在主窗口上时启动助手并立即请求退出。AppKit 因此拒绝退出并记录 `App termination blocked by modal sheet`；更新助手等待旧进程超时，而界面没有接收失败结果的通道。

修复版本已在临时目录完成真实端到端升级：一个报告为 1.3.0 的修复版应用在线下载正式 1.3.1 DMG，完成校验、关闭更新 Sheet、退出、原位替换并以 1.3.1 自动重启；AppKit 日志中不再出现模态 Sheet 阻止退出的记录。端到端检查中另行发现的 DMG 卸载失败也已修正，并纳入最终安装包验收。

Madedown 支持 macOS 13 及更高版本。下载版使用 ad-hoc 签名，未经过 Apple 公证，因此首次启动时 macOS 可能要求在“系统设置 → 隐私与安全性”中确认。
