# Madedown 1.3.3：保留空行与修复列表编辑

[English](https://github.com/zhxnix/Madedown/blob/v1.3.3/Docs/UPDATE_ANNOUNCEMENT_1.3.3.md) | **简体中文**

Madedown 1.3.3 修复切换标签页、切换源码与渲染模式、保存或重新打开应用后，空行及文末回车消失的问题。

## 修复内容

- 保留文首空行、连续段落空行、列表项间的空行和文末回车。
- 图片与代码块周围的空行不再随反复渲染、保存而增加。
- 有序列表按回车后，光标保持在新插入的列表项；连续回车时编号正常递增，不会退回上一项。
- 包含此前针对 1.3.0 空有序列表回车卡死的修复。
- 包含 1.3.2 的应用内更新修复：退出前关闭模态更新窗口、显示更新助手失败原因，并正确清理挂载的安装镜像。

## 安装方法

下载 **Madedown-1.3.3.dmg**，替换“应用程序”中的 `Madedown.app`。已有文档标签页和会话数据会保留。

仍在使用 **1.3.0 或 1.3.1** 的用户，请手动安装一次：旧版点击“安装并重新启动”可能卡住。1.3.2 及后续版本可使用 **帮助 → 检查更新…**。

下载版适用于 Apple Silicon Mac，支持 macOS 13 及更高版本，使用 ad-hoc 签名，未经过 Apple 公证。

## 验证结果

Debug 与 Release 功能自测均通过。已在原生 macOS 窗口验证有序列表连续回车、切换标签页、切换编辑模式、保存及退出重开，空行保持一致。
