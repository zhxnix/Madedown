# Madedown 1.3.1：有序列表编辑热修复

[English](https://github.com/zhxnix/Madedown/blob/v1.3.1/Docs/UPDATE_ANNOUNCEMENT_1.3.1.md) | **简体中文**

Madedown 1.3.1 是一次聚焦所见即所得编辑器有序列表稳定性的修复版本。

## 修复内容

- Markdown 快捷输入扫描器识别有序列表标记后，会稳定推进到当前整行之后。
- 只有编号标记的空列表项后接换行时，不再反复扫描同一行并卡住主线程。
- 在空有序列表标记后按退格会退出到普通段落输入状态。
- 退出列表后继续输入文字或按回车，会保持普通段落，不会悄悄重新开始列表。

## 回归覆盖

自动化测试现已覆盖“只有编号标记的空行”扫描，并验证有序列表退格后会清除继承的列表输入状态。发布前还会执行 Debug 与 Release 自测、更新助手事务测试、性能预算、开源内容审计、DMG 挂载检查和严格的 ad-hoc 签名校验。

Madedown 继续支持 macOS 13 及更高版本。下载版使用 ad-hoc 签名，未经过 Apple 公证，因此首次启动时 macOS 可能要求在“系统设置 → 隐私与安全性”中确认。
