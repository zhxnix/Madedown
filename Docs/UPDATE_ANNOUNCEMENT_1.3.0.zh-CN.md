# Madedown 1.3.0 更新预告：智能粘贴、中英界面与在线更新

[English](UPDATE_ANNOUNCEMENT_1.3.0.md) | **简体中文**

Madedown 1.3.0 把重点放在“写起来更顺”和“长期使用更省心”上。这一版补齐了 Markdown 智能粘贴、常用格式快捷键、中英界面和 GitHub 原位更新，也集中修复了表格、标签视口、深色模式和界面一致性问题。

## Markdown 源码，粘贴后直接变成所见即所得

在所见即所得窗口粘贴疑似 Markdown 的纯文本时，Madedown 会先询问如何处理：

- **转换为 Markdown**：标题、列表、引用、代码、表格和行内格式直接转成可编辑的实时渲染内容。
- **粘贴源码**：完整保留 `#`、`**`、`~~` 等原始字符。
- **取消**：不改动当前文档。

普通文本和图片粘贴仍沿用直接流程，不会频繁弹出无关提示。

## 常用格式快捷键

- `⌘B`：切换加粗
- `⇧⌘X`：切换删除线

两个快捷键同时支持源码和所见即所得模式。选中文字时直接切换格式；没有选区时会插入并选中可立即替换的占位内容。

## 默认英文，可即时切换简体中文

界面现在支持英文和简体中文。全新安装默认英文；可以通过顶部栏的地球按钮或“语言”菜单即时切换，重启后仍保留选择，也不会改变现有会话文件格式。

本地化覆盖菜单、对话框、标签页、快速打开、标题目录、表格控件、斜杠菜单、粘贴提示、状态文字和更新器各状态。文档内容和文件名不会被翻译。

## 顶部栏合并为紧凑单行

窗口内的“打开、保存、复制、图片”文字按钮已经移除，这些操作继续通过 macOS 菜单和快捷键提供。标签页上移到原操作按钮区域，与编辑模式、宽度、窗口布局、置顶和语言控件共用一条紧凑顶部栏。

## 从 GitHub 检查更新，并在原路径安全替换

“帮助 → 检查更新…”不再只是打开网页。Madedown 会：

1. 查询项目的 GitHub 最新稳定 Release；
2. 使用语义版本规则与当前版本比较；
3. 展示版本号、更新说明、安装包名称和下载进度；
4. 优先选择 DMG，也支持包含完整应用的 ZIP；
5. 校验 Bundle ID、Release 版本、主程序与代码签名；
6. 用户确认后退出当前版本，由独立更新助手在原路径完成替换；
7. 新版本启动成功后删除旧版本、下载包和暂存目录，失败则自动回滚并重新打开旧版本。

更新只会在用户手动触发时联网，下载地址必须是批准的 GitHub HTTPS 域名。目标目录需要更高权限时，macOS 会显示管理员授权窗口。流程只替换当前启动的 `Madedown.app`，不会安装出第二份应用，也不会扫描其他目录中的同名副本。

## 更稳定的表格与标签视野

- 表格段落终止符继续保留 AppKit 原生表格布局属性。
- 滚动时按完整行列几何补画像素对齐网格，横线和竖线不再分段。
- 覆盖层直接使用原生边框区域，消除曾短暂出现在首尾行内部的额外横线。
- 标签页同时恢复顶部可见文字、像素偏移和光标，切回后仍看到原来的上下文。
- 标题栏 Logo 随系统标签色变化，在深色模式下保持清晰。
- 内容区左右留白小幅增加，标签页、内容容器、按钮和标题目录统一为 6 pt 小圆角。
- 段落软换行重新解析后不再折叠为空格。

## 质量与兼容性

本次更新继续保持原生 Swift / AppKit / SwiftUI 架构，没有增加常驻后台进程。更新助手只在用户确认安装后短暂运行。自动化回归新增语言默认值和代表性翻译，并继续覆盖智能粘贴、格式切换、表格布局和边框几何、标签视口锚点、语义版本、安装包选择、不安全地址拦截、应用校验，以及带回滚的原位替换事务。

Madedown 仍支持 macOS 13 及以上版本。当前开源构建使用 ad-hoc 签名且未经过 Apple 公证，首次安装时 macOS 仍可能要求在“隐私与安全性”中确认。
